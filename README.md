# Fates of Aeterna

A playable, single-file tactical combat prototype inspired by Greek and Roman mythology.

## Play

[Open the live game](https://djawesome9.github.io/fates-of-aeterna/)

Build two covenants of one to five characters, choose a leader, and fight through turn-meter combat using faction mechanics such as Artemis’ Quarry, Argonaut Coordinated Assault, Roman Discipline, Arachne's Thread, and Talos’s Bronze Guardian.

The prototype runs directly in a modern browser with no build step or package installation.

## Local use

Open `prototype/index.html` in a browser.

## Highlights

- 40 playable Greek and Roman mythic characters
- Eleven curated team presets, including Talos Alone, Hades’ Court, and Artemis’ Hunt
- Deterministic turn-meter combat and AI
- Responsive desktop and mobile layouts
- Local painted character artwork
